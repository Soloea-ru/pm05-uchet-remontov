# Чек-лист модуля 3

## База

- [x] Сценарии регистрации, своих заявок и общего списка закрыты схемой `sql/schema.sql`.
- [x] Внешние ключи и проверки длины включены в таблицах.
- [x] Индексы по абоненту, статусу, варианту работ, дате визита и составной индекс списка — `sql/migration_module3.sql`.
- [x] Смена статуса пишет `updated_at`.

## Интерфейс и данные

- [x] Формы создают и показывают заявки, фильтр на панели диспетчера ограничивает выборку.
- [x] Ошибки полей остаются рядом с полями, логин проверяется до отправки.
- [x] На ширине телефона таблица становится карточками, сценарии те же.

## Анимации

- [x] Карточка слегка поднимается при наведении.
- [x] Кнопка сдвигается на 1px.
- [x] Уведомление выезжает снизу и закрывается само или крестиком.
- [x] Слайд сменяется растворением за 0.45 с.
- [x] Полоска статуса показывает ход заявки.
- [x] `prefers-reduced-motion` отключает эти эффекты.

## Оптимизация

- [x] У слайдов заданы `width` и `height`, у нижних кадров `loading="lazy"`.
- [x] В карусели JPEG вместо несжатого PNG, сравнение в `docs/images/optimization.md`.
- [x] Стили и сценарии без сторонней библиотеки интерфейса.
