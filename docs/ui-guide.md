# UI-гайд «СвязьСервис»

Экранная шпаргалка открывается по адресу `/guide`.

## Цвет

| Роль | HEX | Где |
| --- | --- | --- |
| Фон | `#f4f0e6` | страница |
| Карточка | `#fffdf8` | формы, таблицы |
| Текст | `#1c241f` | основной текст |
| Вторичный текст | `#3e4c46` | пояснения |
| Акцент | `#0b4f4a` | кнопки, ссылки, логотип |
| Внимание | `#8a4b08` на `#f8e6cf` | статус «Новая», фокус |
| Готово | `#14663a` на `#d9f0e3` | статус «Выполнена» |
| Ошибка | `#8d1d1d` на `#f8d6d6` | текст ошибки и неуспешный вход |

Белый текст на `#0b4f4a` и тёмный текст на фоне светлее порога 4.5:1.

## Шрифт

Заголовки — Candara. Текст, кнопки и поля — Segoe UI, 16px. Если Candara нет, используется Segoe UI.

## Сетка

Рабочая ширина 1120px. На ширине до 900px герой, три карточки и фильтры становятся одним столбцом. На 390×844 поля страницы 12px с каждой стороны от колонки `calc(100% - 24px)`, кнопки и поля не ниже 44px.

Таблицы на узком экране превращаются в карточки: подпись поля берётся из `data-label`.

## Компоненты

- Кнопка основная — заливка акцентом, белый текст, скругление «капсула».
- Кнопка тихая — прозрачная, обводка акцентом.
- Поле с ошибкой — красная рамка и текст под полем, связь через `aria-describedby`.
- Фокус — контур `#8a4b08` толщиной 3px.
- Статусы — три метки и полоска шагов: пройденный шаг бирюзовый, текущий коричневый.
- Слайдер — четыре кадра 1200×675, смена каждые 3 секунды, кнопки «назад/вперёд» и точки. При `prefers-reduced-motion` автопрокрутка выключена.

## Иконки

Логотип и стрелки слайдера — встроенный SVG, без внешнего шрифта иконок.
